# AppleSkin para Horizon

AppleSkin añade mejoras visuales relacionadas con la alimentación en Minecraft sobre Horizon.

Muestra la saturación y el agotamiento en la barra de comida, permite previsualizar lo que restaura el alimento que llevas en la mano y añade valores de hambre y saturación a las descripciones de los objetos. También ofrece una estimación de la salud que puede recuperar la comida.

Es un mod principalmente visual: no añade objetos ni cambia recetas.

## Descarga

- [AppleSkin 3.0.3 para Horizon nightly](./appleskin-3.0.3.hmod)
- [Icono del mod](./appleskin-icon.png)

Copia el archivo `.hmod` en la carpeta `horizon-mods/` de la instancia de Horizon.
